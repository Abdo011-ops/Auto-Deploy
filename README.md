# 🌙 مشروع موقع مسلم (Muslim App)

موقع إسلامي متكامل يهدف لتوفير الخدمات الإسلامية، التواصل والتفاعل بين المستخدمين.

## 🚀 المميزات الرئيسية:
- 📹 **شاشة الفيديوهات:** عرض فيديوهات إسلامية قصيرة ورفع الميديا باستخدام Cloudinary.
- 💬 **الدردشة العامة والخاصة:** شات جماعي بين المستخدمين ومحادثات خاصة سريعة.
- 📞 **المكالمات المباشرة:** دعم مكالمات الصوت والفيديو المباشرة عبر WebRTC.
- 🔑 **تسجيل الدخول وقاعدة البيانات:** إدارتها بالكامل عبر Firebase.

## 🛠️ التقنيات المستخدمة (Tech Stack):
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Database & Auth:** Firebase Realtime Database
- **Media Hosting:** Cloudinary
- **Video Calls:** WebRTC / Simple-Peer
